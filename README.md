# 🕶️ MetaLens — Premium Meta Glasses Reviews Platform

MetaLens is a high-performance, full-stack reviews ecosystem built to aggregate, analyze, and manage customer experiences for the **Meta Ray-Ban Smart Glasses**. It couples a state-of-the-art **Glassmorphic Dark-Mode Dashboard (Frontend)** with a secure, highly robust **MVC RESTful API (Backend)** powered by Node.js, Express, and MongoDB.


## 🌐 Full Stack Project Overview

MetaLens is a fully integrated, production-ready full-stack application designed to aggregate, analyze, and manage customer feedback for Meta Ray-Ban Smart Glasses. The application seamlessly bridges a modern client dashboard with a secure database backend:

*   **Integrated Client-Server Flow**: The application combines a high-performance **React + Vite** frontend with a robust **Node.js, Express, and MongoDB** backend. In development, both processes are run concurrently via a unified command (`npm run dev`). In production, the React frontend is compiled into optimized static assets served directly by the Express server for single-host efficiency.
*   **Persistent Light/Dark Theme Engine**: Built with premium CSS variables, the interface features a responsive dark/light mode toggle. The selected theme persists in `localStorage`, transitioning background styles, neon glow opacities, and interactive data charts smoothly.
*   **Analytical Data Visualizations**: Integrates **Chart.js** to present key feedback trends:
    *   *Monthly average rating trends* via smooth, filled area line charts.
    *   *Rating distribution bar charts* showing score frequencies.
    *   *Verified vs. unverified purchase ratios* in cutout doughnut charts.
    *   All charts dynamically redraw gridlines, tick colors, and hover tooltips when switching themes.
*   **AI-Synthesized Insights & Chat Copilot**: An interactive AI review companion lets users query the dataset in real-time. The dashboard aggregates automated review summaries, pros/cons lists, and overall verdicts generated by backend analytics.
*   **Granular Filters & CRUD Management**: Users can dynamically filter reviews by rating, verification status, country, device used, and search queries with input debouncing. Authenticated users can create, update, and delete reviews directly from the UI.
*   **Secure MVC REST API**: Secure authentication is handled via JWT Access and Refresh tokens. Route-specific rate-limiting middleware shields database endpoints against brute force, and admin access roles guard critical management tools.

## 🚀 Local Getting Started Guide

### Prerequisites

* Node.js (v18+)
* MongoDB (Local Instance or MongoDB Atlas)

### Setup Steps

#### 1. Navigate to Backend Directory

```bash
cd meta_glasses_reviews_harshit_pandya/backend
```

#### 2. Configure Environment Variables

Create a `.env` file:

```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/meta_glasses_reviews
JWT_SECRET=your_glowing_jwt_secret_key_here
NODE_ENV=development
```

#### 3. Install Dependencies

```bash
npm install
```

#### 4. Seed Database

```bash
node services/seed.js
```

#### 5. Start Development Server

```bash
npm run dev
```

Server runs at:

```text
http://localhost:5000
```

#### 6. Run Automated Tests

```bash
node services/test_api.js
```

## 🔒 Security Middleware Budgets

To protect the infrastructure from abuse and excessive database load, custom rate limits are applied:

* `POST /auth/register` → **5 registrations/min**
* `POST /auth/login` → **10 attempts/min**
* `GET /reviews` → **30 requests/min**
* `GET /search` → **15 requests/min**
* `POST /reviews` → **5 creations/min**
* `DELETE /reviews/:reviewID` → **5 deletions/min**
* `POST /import/json` → **2 uploads/min**
* `GET /admin/*` → **10 requests/min**

> Requests with the header `x-testing: true` bypass limits during automated testing.
